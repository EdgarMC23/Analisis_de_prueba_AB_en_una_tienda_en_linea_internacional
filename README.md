En este emocionante proyecto, nos propusimos evaluar una prueba A/B para un nuevo sistema de recomendaciones, buscando identificar un aumento del 10% en la conversión a través de las etapas clave de la página de producto, el carrito y la compra. Empleando pandas para la manipulación de datos, matplotlib y seaborn para la visualización, y statsmodels para robustas pruebas estadísticas, realizamos un análisis exhaustivo. Un logro significativo fue la identificación proactiva de desafíos cruciales en la configuración de la prueba, como un desbalance notable en los grupos experimentales y una anomalía en el embudo de conversión. Este descubrimiento, si bien resaltó la necesidad de precauciones en la interpretación inicial, nos brindó una valiosa oportunidad para profundizar en la ciencia de datos, formulando recomendaciones estratégicas para asegurar la validez y el éxito de futuras pruebas. ¡Un claro ejemplo de cómo el análisis riguroso transforma los datos en conocimientos accionables!
