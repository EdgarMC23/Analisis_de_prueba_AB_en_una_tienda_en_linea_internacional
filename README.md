# An-lisis-de-prueba-A-B-en-una-tienda-en-l-nea-internacional
El objetivo del proyecto fue verificar si la prueba A/B se ejecuto correctamente y comprobar si hubo cambios entre el nuevo sistema con el sistema anterior. Identifiqué una anomalía crítica en el embudo de conversión, lo que requiere una investigación urgente por parte de la tienda para asegurar un seguimiento preciso de los eventos.
